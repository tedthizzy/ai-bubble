# EDGAR maturity re-extraction, September 16, 2026

The first September deal extraction treated generic prospectus expiration dates as debt maturities. A [SpaceX FWP source](https://www.sec.gov/Archives/edgar/data/1181412/000162828026041365/eu_interviewtranscript06.htm) says its prospectus validity expires June 11, 2026. The old candidate assigned that date to a $20 billion bridge facility. The corrected `extract_maturity_date` requires an explicit debt maturity/due phrase, or an expiration phrase in debt-instrument context. The same saved SpaceX source now yields a $20 billion pending deal candidate with no extracted maturity. A separate $1.5 billion historic revolver capacity had zero drawn at March 31 in its own filing, so the old $21.5 billion raw SpaceX rank was gross commitments, not drawn debt.

A standalone offline driver re-read the immutable `data/edgar_offline_pre_main_snapshot_2026-09-16/edgar_document_inventory.csv` and joined each filing URL to the original September selected or offline-exhibit manifest. It verified SHA-256 and byte count for all 6,975 saved raw documents and made zero network requests. The same 229 rows also changed confidence fields because the parser no longer awards maturity evidence. Deal titles, IDs, amounts, classifications and other content fields match the original snapshot. This correction materially weakens any near-term refinancing rank built from the old September deal tables. It does not certify every remaining maturity or turn candidate commitments into drawn debt.
